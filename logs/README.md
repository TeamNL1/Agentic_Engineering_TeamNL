# Logs

Alleen beknopte, geschoonde ontwikkelverslagen in `agent-sessions/` worden
vastgelegd in Git. Ze zijn handgeschreven projectdocumentatie en mogen zolang
het project bestaat bewaard blijven. Geen ingevoerde boodschappen of credentials.
De browserapp maakt geen runtime-logs. Eventuele lokale runtime- en testlogs
blijven buiten Git en mogen na controle verwijderd worden.
