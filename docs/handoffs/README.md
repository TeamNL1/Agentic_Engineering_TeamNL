# Overdracht en sessieverslagen

Bewaar hier beknopte, geschoonde verslagen van wijzigingen, keuzes, controles,
beperkingen en volgende stappen. Namen: YYYY-MM-DD-HHMM-onderwerp.md. Deze
projectdocumentatie mag in Git en blijft zolang het project bestaat bewaard.
Geen secrets, persoonsgegevens, ingevoerde credentials of ruwe uitvoerlogs.
Historische verslagen beschrijven de toenmalige paden en afspraken.
